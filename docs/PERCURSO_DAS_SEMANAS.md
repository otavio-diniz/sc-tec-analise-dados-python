# Percurso das semanas

Este índice acompanha a trajetória do curso SC TEC T8 desde a Semana 01. O Material Vivo cresce conforme novas fontes são tratadas. O percurso cronológico localiza o conteúdo; os Guias/Cadernos seguem a ordem em que é mais fácil aprender. Um tema introduzido cedo pode ser retomado em outro eixo semanas depois.

**Como usar:** localize sua semana, leia a síntese, escolha os Guias correspondentes e faça os Cadernos. Para executar ferramentas reais, siga a ambientação e os laboratórios. As indicações são de estudo, não afirmação de presença, nota ou conclusão.
