# Semana 07 — Mini-Projeto de Análise de Dados de Varejo

**Curso:** SC TEC — Análise de Dados com Python · Turma T8  
**Vínculo curricular:** Módulo 1 · Semana 07  
**Natureza:** referência a um projeto acadêmico independente, não um exercício sintético da biblioteca.

## Projeto apresentado na Semana 07

O mini-projeto investiga dados de varejo com **Python e Pandas no Google Colab**. O percurso documentado inclui leitura da base, diagnóstico de qualidade, decisões justificadas de tratamento, exploração e interpretação dos resultados, exportação e instruções de reprodução.

**[Acessar o repositório do mini-projeto — Semana 07](https://github.com/otavio-diniz/Miniprojeto_Otavio_Diniz_T8)**

No repositório original estão o notebook, o README próprio, o contexto da base e as limitações do trabalho. Consulte a documentação de origem antes de reutilizar qualquer dado.

## Relação com esta biblioteca de estudos

- **Guia/Caderno 03 — Pandas:** leitura, tipos, valores ausentes, duplicidades, tratamento justificado, agrupamentos e interpretação.
- **SQL relacional e PostgreSQL:** ligação conceitual futura com entidades, consultas e granularidade. O mini-projeto original não é uma implementação em PostgreSQL.
- **MongoDB e NoSQL:** comparação futura entre abordagens de modelagem, sem atribuir uso de MongoDB ao mini-projeto da Semana 07.
